# ADR 0004-laya — Optional, managed Laya System 1

Date: 2026-10-06. Status: accepted for design (future capabilities, not delivered).

## Context
Sermofur mission: epistemic invariants, isolation and an installable local product.

## Decision
A typed decisions adapter, a separate managed runtime, lazy load/unload, timeout, pinned model
with checksum, real inference. Without Laya: degraded mode and the host's System 2. A prediction
grants neither rights nor truth.

## Alternatives
A Core dependency on Laya rejected; a fake fallback that pretends to infer rejected.

## Consequences
Boundary tests are required; changes go through a new ADR.
