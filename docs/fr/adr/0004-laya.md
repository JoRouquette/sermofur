# ADR 0004-laya — Laya System 1 facultatif et géré

Date : 2026-10-06. Statut : accepté pour conception (capacités futures non livrées).

## Contexte
Mission Sermofur : invariants épistémiques, isolation et produit installable local.

## Décision
Adaptateur de décisions typées, runtime géré séparé, chargement/déchargement paresseux, timeout,
modèle épinglé avec somme de contrôle, inférence réelle. Sans Laya : fonctionnement dégradé et
System 2 du host. Une prédiction n'accorde ni droits ni vérité.

## Alternatives
Dépendance du cœur à Laya rejetée ; faux repli qui prétend une inférence rejeté.

## Conséquences
Tests de frontière requis ; toute évolution passe par un nouvel ADR.
